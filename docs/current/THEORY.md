# 数学定义与证明

本文采用自然对数。固定问题、图像和已经生成的词元前缀。条件分布p和参考分布q在保留候选S上均为正；弃权候选集合A及其补集B在S内均非空。首先讨论有限候选空间，再给出完整序列关系。

## 1. 对比操作

令 d_i=log p_i−log q_i。VCD型局部变换为

m_i = 1{i∈S} p_i exp(αd_i) / Z，
Z = Σ_{j∈S} p_j exp(αd_j)。

它根据候选在正常条件与参考条件之间的相对支持度重新分配概率。候选限制S与α固定。M3ID在每一步确定实际权重后也具有这个形式，其S为全词表。SID使用不同的参考构造。DoLa的最终层减早期层对数概率与DeCo的加性校正分别保留原公式，不强行代入同一个α。

## 2. 语义分组与对比操作的关系

记p_S、q_S为在S上归一化的分布，O_p(A)=p(A)/p(B)。Rényi散度定义为

D_r(u||v) = log Σ_i u_i^r v_i^(1−r)/(r−1)。

r→1时取KL散度。它衡量两个分布如何在同一组候选内部安排概率。

以下关系精确成立：

log O_m(A) − log O_p(A)
= [log O_{p_S}(A) − log O_p(A)]
+ α[log O_{p_S}(A) − log O_{q_S}(A)]
+ α[D_{1+α}(p_S(.|A)||q_S(.|A)) − D_{1+α}(p_S(.|B)||q_S(.|B))]。

第一项来自候选限制。第二项来自参考计算对弃权整体相对于具体答案的偏好。第三项来自两个条件在各组内部选择不同表达的程度。

证明：把A内求和写成
Σ_{i∈A}p_{S,i}^{1+α}q_{S,i}^{−α}
= p_S(A)^{1+α}q_S(A)^{−α}
  × exp[α D_{1+α}(p_S(.|A)||q_S(.|A))]。
对B作同样分解，两式相除并取对数，得到后两项；再补上p到p_S的变化，得到完整关系。公共归一化常数在概率比中消去。

当参考对UNKNOWN分配高概率而对UNCLEAR分配较低概率，单个UNKNOWN受到压低，UNCLEAR仍可能保有竞争力。跨表达是否共同下降由三项的总和决定。因此，仅有参考弃权总概率高于条件分布这一事实，不足以确定最终全部弃权表达的变化方向。

这里A必须是已经定义的候选分组。把几个词元的首个子词直接称为“所有完整弃权回复”会改变测量对象。代码将初始词元集合、有限完整回复集合和自由生成后的语义标签分别保存。

## 3. 强度变化

在S、p、q固定时：

d m_α(A)/dα = Cov_{m_α}(1_A,d)。

证明：d m_i/dα=m_i(d_i−E_m[d])，对A求和即可。全部弃权表达是否随着强度增加而减少，取决于它们的平均相对支持与全体候选的比较。α增大不提供无条件的弃权下降保证。

## 4. 单个候选的翻转边界

对仍在S内的两个候选a、b：

log[m(a)/m(b)]
= log[p(a)/p(b)] + α{log[p(a)/p(b)]−log[q(a)/q(b)]}。

假定正常条件下a领先。当参考对a的相对支持更强时，存在一个翻转阈值，等于原有领先幅度除以参考额外领先幅度。正强度越过该阈值，b超过a。若参考额外领先幅度非正，这对候选不会沿此方向翻转。模型的完整回复继续取决于其他竞争候选与后续词元。

## 5. 完整序列

对实际自回归概率P(y)=Π_t p_t(y_t|y_<t)，变换后的M(y)满足

log M(y)−log P(y)
= Σ_t α_t log[p_t(y_t|y_<t)/q_t(y_t|y_<t)]−Σ_t log Z_t(y_<t)。

任意一步不在支持内，该序列的M概率为零。所有Z_t都依赖已经生成的前缀，必须逐步保留。

对于已列出的有限完整回复集合，将每条实际词元序列与允许的终止符作为互斥结果，记D(y)=log M(y)−log P(y)，则

log O_M(A)−log O_P(A)
= log E_{P(.|A)} exp D(y) − log E_{P(.|B)} exp D(y)。

这是有限完整回复集合内的精确关系。自由回复的实际弃权率由完整语义标注另行计算，二者不混用。

## 6. 指令保持解码

令g为带弃权引导的清晰图像对数概率，c为无弃权引导的清晰图像对数概率，r为无弃权引导的参考条件对数概率。定义

s = g + α(c−r)。

对保留候选进行softmax，并使用与带引导直接分布相同的候选限制。三个输入来自同一个冻结模型，共享生成前缀。

推导采用三个要求：
1. 带引导分数变化δ加入g时，新分数的变化为δ；
2. 删除弃权引导使g=c时，恢复原VCD分数；
3. 采用这三个条件的线性分数组合，不引入可训练参数。

设s=a g+b c+d r。第一项要求给出a=1。代入g=c后，第二项要求a+b=1+α且d=−α，因此b=α。系数在这个已明确的函数族中唯一。

在同一候选集合内，对任意两个候选i、j：

[s_g(i)−s_g(j)]−[s_n(i)−s_n(j)]
= [g_i−g_j]−[c_i−c_j]，
其中s_n=(1+α)c−αr。

也就是说，加入弃权引导对候选相对分数的影响，保持为直接解码中的指令影响。softmax的共同归一化量不改变这一关系。

若视觉两条件相同c=r，新分数等于g；若没有弃权引导g=c，退化为普通VCD。删除任一条件会失去其中一项要求：没有g则无法保持原指令；没有c则把指令改变与图像变化混合；没有r则失去视觉参考对比。


### 最优化解释

在固定保留候选S上，将g归一化后的基线概率记为G，将视觉相对支持记为d=c−r。选择新分布π，使以下目标最大：

J(π)=α E_π[d]−KL(π||G)。

第一项奖励视觉相对支持较强的候选，第二项限制新分布偏离带弃权引导的原分布。它使用一个已有对比强度α，不增加新的权衡参数。

因为G在S内为正，负KL严格凹，目标具有唯一最大值。设Z=Σ_{i∈S}G_i exp(αd_i)，则

J(π)=log Z−KL(π||M)，
M_i=G_i exp(αd_i)/Z。

KL非负且仅在π=M时为零，因此唯一最优解就是s=g+α(c−r)的softmax。这给出了分布选择的完整目标与闭式解。其保证针对声明的概率目标；正确回答和合理弃权由统一的实验指标共同评价。

## 7. 与原始带引导VCD的差别

记q_g为带引导参考对数概率。原始分数为s_old=(1+α)g−αq_g。两者差为

s−s_old = α[(q_g−r)−(g−c)]。

括号内是弃权引导在参考条件与清晰图像条件下产生的不同作用。当两种条件中的作用完全相同，两种解码对候选相对分数相同。这也是四条件共享前缀测量要检验的对象。

## 8. 数学保证的范围

新方法约束固定前缀、共同保留候选之间的分数关系。原始VCD与新方法都使用g构造候选限制，因此两者共享支持。不同引导条件的支持可能变化，该变化单独记录。M3ID扩展中的门控由无引导清晰分布计算，时间偏移由无引导问题长度计算，使视觉增量独立于弃权指令。

指令保持可以同时用于UNKNOWN、UNCLEAR和完整自然语言表达，因为公式作用于全词表。语义标签只参与测量。最终正确率、原有弃权保留率和具体答案纠正保留率是实证结果，不由局部分数恒等式确定。

DExperts已经使用基础分数加专家分数减反专家分数的乘积专家形式。本文采用该已知计算家族，将三个条件固定为引导正常输入、无引导正常输入和无引导参考输入；贡献应放在输入选择、指令保持要求及实验效果。[S5]

## 9. 扩展到其他分数组合

对于共同保留候选S内的一般分数 λ log p+μ log q，令
C_A=Σ_{i∈A}p_S(i|A)^λ q_S(i|A)^μ，C_B同理，则

log O_m(A)−log O_p(A)
= 支持变化 +(λ−1)log O_{p_S}(A)+μ log O_{q_S}(A)+log C_A−log C_B。

证明来自分别对A与B提取组概率，再相除。VCD与SID对应λ=1+α、μ=−α；DoLa的实际对数概率差对应λ=1、μ=−1；DeCo在选定层与系数后对应λ=1、μ为正校正系数。实际候选集合与选层规则继续由各方法决定。

负参考系数使参考分布对弃权的较高相对支持成为向下调整的一个来源。整体结果仍包含组内表达分配和候选支持。层级名称本身不确定变化方向。这一关系允许按照实际算子与参考分布解释不同方法的共同作用。

## 10. CDA正文公式与边界

CDA视觉迁移按用户裁定采用正文式(6)，在同一已生成前缀上分别计算无图问题与带图问题的熵Hp、Hc，以及两个空输入条件的熵Hnp、Hnc：

rp=max(Hp−Hnp,0)/Hnp，rc=max(Hc−Hnc,0)/Hnc。

正文式(7)给出wp=rp²/(rp+rc)、wc=rc²/(rp+rc)，wa=1−wp−wc。最终分数为wp zp+wc zc+wa za，再对词表归一化；zp、zc、za分别来自无图问题、带图问题、带图加弃权指令。两个空输入校准会话仍使用[N/A]问题及均匀图像，并共享同一完整生成前缀。这里不采用CDA-M的动量。

该熵差方向使rp和rc可以超过1，因此wa可以为负。实现保留其真实值，不clamp、不将权重softmax，也不作“三个权重必然非负”的保证。每一步记录Hp/Hc/Hnp/Hnc、rp/rc、wp/wc/wa、negative_wa及实际词元对数概率；输出的negative_wa_steps只计数该条实际轨迹，不推断未运行条件的发生率。

边界沿用原实现：Hnp或Hnc非正时，式(6)数学未定义，任务失败并在错误记录中保存熵、失败前缀与已完成轨迹，不生成替代标签或默认混合。原实现没有epsilon分母正则项，本次未加入任何epsilon。rp+rc=0时，式(7)为可去的0/0；保留沿非负象限趋近原点的连续延拓wp=wc=0、wa=1，并逐步标记zero_sum_extension。由于0≤rp²/(rp+rc)≤rp，两项均趋于0。正分母下若浮点计算仍产生非有限系数，则明确记数值失败，不截断权重。
