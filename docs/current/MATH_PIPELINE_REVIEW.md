# Mathematical and task-integrity review — 2026-09-19

Reviewer: independent Codex subagent `/root/math_pipeline_audit`. This review read the research-writing requirements, current paper story, theory, study specification, annotation/scoring, runtime and sources documents, paper outline, and project AGENTS in full. The task was limited to probability, decoding, task expansion, exact-prefix and complete-sequence measurements, annotation/scoring, reports, and their entry scripts/tests. It did not execute GPU generation or inspect intervention results.

## Findings and disposition

1. **P1 — Reports could silently shrink the experiment. Fixed.** A method previously scored only its available paired subset. Missing probe/closed records became lack of behavioral support, and duplicate evidence records could overwrite each other. `evaluate` now requires the full available direct set per condition. `validate_report_coverage` additionally checks all frozen experiment and ten-attempt task identities against the supplied complete manifest and selected model/dataset list before formal report construction. The observed response key set must equal that frozen task universe exactly; extra unselected models, extra conditions, census/unguided records and forged model identities are rejected before evaluation. Food-101 closed records must exactly cover selected evaluation samples, and their 101 candidate names must equal the frozen full-manifest class-name set, with consistent sample identity, lengths, mean scores and rank. Missing/duplicate evidence terminates reporting. Entire missing methods and jointly missing direct/intervention samples are covered by regression cases.

2. **P1 — Complete-response candidates did not cover all registered terminators. Fixed.** Already-terminated donors previously retained only their observed EOS. All donor bodies now receive every registered EOS; conflicting semantic assignments and interior EOS remain errors. The donor script requires all four direct prompts per sample and rejects truncated valid donor responses. Invalid donors remain visibly excluded from the concrete/abstention candidate groups. A pool with no concrete donor is explicitly recorded as `no_concrete_donor` rather than supplying a truth-selected competitor.

3. **P1 — Replay could not compute instruction-preserving methods. Fixed.** `step_distribution` is now shared by generation and replay. Instruction-M3ID replay uses the neutral-clear gate and neutral prompt offset, and retains actual guided, neutral-clear, reference scores and per-prefix normalizers. Tests reconstruct each chosen token's normalized probability from these values and compare replay with generation. Replay records exact prefixes.

4. **P1 — Mechanism tooling omitted registered layer operators and SID. Fixed in scoped functions.** `measure_path` supports VCD, M3ID, SID, DoLa and DeCo. Layer measurements preserve the actual selected guided and neutral layers and their scores; they do not assert a VCD-form instruction identity. Layer references reject a distinct reference prompt. The complete-response script supports the baseline layer methods and instruction variants, with SID available explicitly. The main agent owns CLI wiring and model-specific admission checks.

5. **P2 — Completion validation trusted keys alone. Fixed.** `verify_complete` checks the stored task fields, full sample, successful status, response text, nonempty token list, and explicit termination flag. A bounded max-token output can still be a completed generation task when `terminated=False`; it cannot serve as a complete donor response. Matching keys with failed status or changed task fields fail verification.

6. **P2 — Semantic revisions could be ignored and scoring could fall back to the whole response. Fixed.** Explicit annotation records take precedence over automatic exact-phrase labels. Formal report construction requires every response, including automatic exact-phrase labels, to have a text-matching entry in the unified annotation file. Concrete correctness requires the endorsed exact answer span. VizWiz requires an explicitly supplied official normalizer; there is no generic-normalization fallback. Repeated attempts must have exactly replicate IDs 0 through 9. Report rows include answer counts, correctness denominators and newly introduced abstention counts. Probe summaries retain full-credit counts, positive-credit counts, total credit and mean official correctness separately. Zero behavioral success means zero total official credit; partial VizWiz credit is not misreported as ten failed attempts. The report's 0/1–7/8–10 success grouping explicitly names positive official credit as its definition, while full-credit counts remain in probe records.

7. **P2 — SID reference prompts were not a full crossed design. Fixed.** Registered SID experiment tasks now enumerate four main prompts by four reference prompts, like the visual reference methods. Layer references remain within their own input prompt because an independent layer-reference prompt does not exist in those operators.
