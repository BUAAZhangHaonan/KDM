# 图表说明

主图按照具体问题安排：原有弃权的去向；同义表达怎样改变整体概率；数学分解的三个成分；保留指令影响的结果；正式方法的正确回答与合理弃权。

所有图使用明确轴名和图例。概率用0–1尺度或统一百分数，准确率差用百分点，不能混用。单图只呈现一项主要比较，不使用饼图、三维球体、过多重复面板或装饰性背景。宽图约7.1英寸，字体至少9pt，PDF嵌入文本矢量、PNG用于快速审阅。字体只使用系统安装版本，不把字体文件放入包内。

本包附图包含用户报告的计数和数学示例。每张图注明来源属性。数学示例的作用是检验公式和说明边界；图内永久保留MATHEMATICAL EXAMPLE。正式论文图由真实结果文件生成，用户交接计数在重新计算后更新。

`src/kdm/visualization.py` 中每个函数都经过实例运行。`scripts/render_figures.py` 提供完整命令。PDF重新渲染后检查文字边界、坐标轴、图例、中文/符号显示与数值一致性。验证细节在 `verification/VALIDATION_REPORT.md`。
