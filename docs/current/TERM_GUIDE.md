# 写作用词与对象

模型行为使用“弃权”“具体回答”“带不确定语气的回答”“正确回答”。对比条件使用“清晰图像条件”“参考条件”“带引导提示”“无引导提示”。涉及概率公式时先说明这些条件的实际输入，再使用变量。

分组对象使用“类别子集”或“模型条件”。参考影响使用“相对支持”“概率比”“分数差”。实验变化使用“纠正率”“致错率”“弃权替换率”“合理弃权保留率”。多种回答表达使用“同义表达”。

正式名称保持VCD、M3ID、DoLa、DeCo、SID、CDA。LLaVA-v1.6-7B注明Mistral骨干。代码中的模型键作为记录身份保留，正文使用全称。

论文措辞由证据决定。参数知识、当前图像辨识、闭集排名、重复正确率和人工可回答性各自有明确对象。解释中使用完整动宾结构，减少无必要的对照句与口语缩略。原始写作要求逐字保存在source_materials，不通过复述替代。
