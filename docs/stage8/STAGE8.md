## 2. 分支判定重做（核心）

### 2.1 主检验（逐样本残差回归）

样本口径与第七阶段分格分析逐字相同（评测半区、答案未变、截断重归一化后的最终
分布置信度、q4b 弃权样本按 `answer_maxp=None` 排除），共 **N = 14656**
（答错 6677），覆盖全部 32 个忠实格。逐样本量：
r = Δ − pred（置信度变化减去温度尖化对照预测的变化；温度参数 T_m 为第六阶段
开发半区一次性拟合的 `T_fit`，直接引用）；w = 直接解码答错指示；
A_m = 格人群干预前准确率。主模型 r = α_m + γ·w + ε（32 个格固定效应，OLS）。

**γ = +0.0097**，95% CI（按模型聚类主口径）**[−0.0013, +0.0208]，含零**。
全部口径：

| 聚类口径 | 95% CI | 含零 |
| --- | --- | --- |
| 模型（4 簇，预登记主口径） | [−0.0013, +0.0208] | 是 |
| 类别（101 个数据类别簇） | [−0.0039, +0.0233] | 是 |
| 方法（4 簇） | [−0.0065, +0.0259] | 是 |
| 格（32 簇） | [−0.0119, +0.0313] | 是 |
| 模型聚类 + t(3) 临界值 | [−0.0082, +0.0276] | 是 |
| 模型整簇自助（B=2000，种子 20260917） | [−0.0008, +0.0186] | 是 |

口径说明（留档）：任务书主检验要求"按类别聚类"；预登记将其读作"模型（4 类）"
并冻结为主口径。本项目第五阶段以来"类别"另有一个既定含义（数据集类别），
故本表把两种读法都算齐：**六种口径全部含零，分支判定对读法稳健**。
逐格自助与第七阶段存档 95% 区间最大偏差 0.005（不同种子流、同 B=2000，
`outputs/tables/stage8_residual_regression.csv` per_cell 行有并排两列可查）。

扩展模型 r = α_m + γ·w + θ·(w·A) + ε：**θ = +0.0606**，
模型聚类 [+0.0159, +0.1053]、类别聚类 [+0.0215, +0.0996]（均不含零）、
格聚类 [−0.0061, +0.1272]（含零）；A=0.9 处拟合差约 +0.031、A=0.16 处约
−0.014。含义：若存在超额抬升，它偏向高准确率人群——只作适用范围证据，
不进入分支判定。

### 2.2 次检验：荟萃与元回归

- **随机效应荟萃**（23 个可判定格，DerSimonian–Laird）：合并
  **d = +0.0149 [+0.0022, +0.0276]**（不含零）；**Q = 203.1**、
  **I² = 89.2%**、τ² = 0.00066。合并为正但格间异质性极高——各格残余方向
  互相打架，这本身是结论。
- **元回归**（d_m 对 A_m）：逆方差 FE 斜率 **−0.0228 [−0.0346, −0.0110]**
  （拟合线在观测 A 范围 [0.16, 0.92] 内穿零）；DL 随机效应权重斜率
  **+0.0330 [−0.0075, +0.0735]**（不显著）；未加权 OLS **+0.0750**。
  **斜率符号随权重口径翻转**：FE 权重被"效应近零但标准误极小"的格主导
  （最大权重 85920：llava16-高组-DeCo，se=0.0034；大效应格权重约 1000）。
  因此残余—准确率梯度**不作为确立结论**，正文三口径并报并声明敏感
  （反例 R9）。

### 2.3 等价性检验（±0.02，TOST 口径：90% 自助百分位区间落入边界）

23 个可判定格中：**4 格等价**（q4b-低组-DoLa +0.003、q9b-低组-DoLa −0.001、
q9b-高组-DeCo −0.001、llava16-高组-DeCo +0.006）；**8 格 90% CI 完全超出
边界**（6 正：q4b-低组-DeCo +0.087、q4b-高组-M3ID +0.068、q4b-高组-DeCo
+0.101、q9b-低组-M3ID +0.051、q9b-高组-VCD +0.125、llava16-高组-VCD +0.094；
**2 负**：q4b-低组-VCD −0.102、q4b-低组-M3ID −0.131）；11 格与边界相交
（不定）。对照第七阶段把"CI 含零"当"可解释"的 11 格：其中 7 格在等价口径下
只是"不定"，不得再标注"与尖化一致"。

### 2.4 分支判定（按预登记冻结规则）

γ 的 95% CI 含零 → **弱版分支**。第一层只写"抬升覆盖全部样本、纠错只覆盖
少数"，第二层维持"近似整体重标定"；荟萃合并 d 虽不含零，但预登记规则明确
荟萃不单独反转主检验方向，其作用是刻画异质性（I² = 89.2%）。

### 2.5 如实报告的四点（任务书 2.6）

1. **第七阶段判定留档**：格数判定 = 可解释 11 / 残余 12 / 样本不足 9（23 判定）；
   二项符号检验双侧 **p = 1.0**（完全不显著）；残余格按组分布：低组 E3/R5、
   高组 E8/R7。该规则被本节统计量取代，**替换理由是统计量问题而非结果问题**：
   "CI 含零"是没有证据反对、不是有证据支持；格数计数忽略每格估计精度；
   可判定格的分布本身与统计功效混淆。
2. **9 个未判定格 = 覆盖限制**：经复核，9 格中 **8 个**是 llava16/internvl4b
   低准确率组（干预前准确率 0.018–0.025），**1 个是 internvl4b-高组-DoLa**
   （答错样本 11 < 20）——任务书"全部是低准确率组"的表述按实际数据修正为
   8/9。逐样本回归覆盖全部 9 格且两组非零（llava16-低组 n_right = 5/9/11/6、
   internvl4b-低组 9/11/3/15、internvl4b-高组-DoLa n_wrong = 11），覆盖缺口
   在名义上补上，但其对 γ 的贡献权重受小子群限制（见
   `docs/stage8/LIMITATIONS_STAGE8.md` 第 2 条）。
3. **残余格分布**：按组计数为低组 5/8、高组 7/15，集中度不高；结合元回归
   三口径斜率不一致，"残余集中在高准确率组"不作为确立陈述。
4. **R1 与 2.2 结论的关系**：R1（q4b-低组 2 格超界为负）与扩展模型的
   θ > 0（A 越低超额越小/反向）方向一致，并入 D2 的适用范围表述；与 FE 元回归
   的负斜率表面一致但机制不同（FE 被近零高精度格主导），故 R1 单列不并入
   元回归条目。

## 3. dogs：数量级一致性检验（口径甲）

拟合基准：food101 忠实实现的 32 个格（`outputs/tables/stage6_core.csv`）的 OLS：
ΔECE = 0.204 − 0.330·准确率，**R² = 0.69**（分方法 R² 0.66–0.96，斜率
−0.22～−0.44）。对每个 dogs 格（16 格）给 95% 预测带：

- **合并预测带命中 14/16**；2 个未命中均为 M3ID 低组格（q4b：实测 +0.0005
  对带 [0.019, 0.386]；q9b：+0.0028 对 [0.020, 0.387]）——近乎不干预的方法
  不满足"增量—准确率"关系，属可解释的未命中。
- **分方法预测带命中 10/16**；另 4 个出带格为 VCD/DeCo 的格（q4b-低组-VCD
  实测低于带下缘、q4b-高组-VCD/DeCo 略高于带上缘、q9b-低组-VCD 低于下缘）。
- **8/16 格为外推**（dogs 低组准确率 0.001–0.004 低于 food101 拟合自变量
  最小值 0.018）。
- 分母说明：dogs 每组 **720**（120 类 × 6 张/类）、food101 每半区每组
  **600**（50 类 × 12 张/类），来源为类别数 × 每类张数，跨域表格已标注。
- **正文措辞**：这是一次数量级一致性检验（方向与量级同 food101 拟合关系
  相容），**不称预测、不据此主张阈值可移植**。
