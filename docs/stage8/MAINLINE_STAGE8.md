# 第八阶段 · 主线文档（MAINLINE_STAGE8，定稿，替换第七阶段版本）

按第八阶段预登记冻结的三支分支规则（`docs/stage8/PREREGISTER_STAGE8.md` 第 3 节），逐样本残差
回归的 γ = +0.0097，95% 置信区间 [−0.0013, +0.0208]（按模型聚类主口径），**含零**；
类别聚类 [−0.0039, +0.0233]、方法聚类 [−0.0065, +0.0259]、格聚类
[−0.0119, +0.0313]、t(3) 口径 [−0.0082, +0.0276]、模型整簇自助 [−0.0008, +0.0186]
全部含零 → 落**弱版分支**：第一层只写"抬升覆盖全部样本、纠错只覆盖少数"，
第二层维持"近似整体重标定"。第七阶段的强版判定（格数 11:12）按预登记留档程序
废止，替换理由是统计量问题（见 `docs/stage8/STAGE8.md` 第 2.6 节），非结果问题。
以下每层不超过三句话，每句数字出处见 `docs/stage8/EVIDENCE_MAP_STAGE8.md`。

**要回答的唯一问题：对比解码纠正不了的那些错误，后来发生了什么？**

本文是诊断型实证论文：对一类流行的免训练干预给出受控测量、机制解释与使用边界，
**不提出任何新方法**。

## 第一层（诊断）

干预抬升置信度的覆盖面与它纠正错误的覆盖面严重不成比例：四个忠实实现的方法在
全部 32 个 模型×组 格上都让未变答案的样本显著更自信（+0.008～+0.372，CI 均不含零），
而把直接解码的错误真正救回的只有 0～33% 的错误样本。
错误答案的确定性同样被显著抬高，且不只在首 token：32/32 格上错误答案的名称层
置信度（各步概率连乘）配对增量 >0 且 CI 不含零（+0.038～+0.518）。
基线可比性由文本级一致性门保证：四模型 0/1200 个 outcome 不一致。

## 第二层（机制）

置信度抬升的主要成分近似一次与样本无关的整体重标定：均值口径下温度对照在
20/28 个可匹配格完整复现干预的增量；第八阶段的汇总逐样本检验维持这一表述——
答错样本超出温度尖化解释的抬升 γ = +0.0097，CI 含零（六种聚类口径一致）。
该残余成分在格间方向不一致、不能作为确立的选择性机制报告：等价检验（±0.02）
下 23 个可判定格中 4 格与尖化一致、8 格超出边界但**正负两向并存**（6 正
2 负）、11 格不定，随机效应异质性 I² = 89.2%。
忠实实现的 M3ID 因上下文压力门控在 86%～98% 的解码步上不施加纠正，且门控在
低准确率组抑制更少（85.9%–87.4%）而高准确率组更多（97.2%–98.0%）——它在更
需要干预的人群上干预更多，纠错收益仍然很小（低组救回率 0.005–0.054）；
干预强度正对照（本地 MIB 变体，非已发表方法）演示了纠错收益足够大时校准符号
可以翻转（准确率 0.179→0.335、ΔECE 转负）。

## 第三层（后果）

该抬升的校准代价可以被一次性常数校正处理掉大半：开发半区估偏移、评测半区减去后，
高准确率组 11/16 格的校准恢复到直接解码水平且答案逐样本不变。
但校正只修把握、不修对错：低准确率人群校正后准确率一个不变，错误存量原样保留，
且其中错误答案的确定性反而更高。
常数只是近似——开发半区偏移与评测半区增量的逐格漂移为 −0.060～+0.038（5/16 格过
校正），它与四格增量的非均匀（27/32）是同一件事的两侧：增量并非严格样本无关。

## 三条支撑（性质声明）

1. 干预近似固定增量的置信度放大器，增量随强度单调（α=0.5/1/2 → 0.199/0.260/0.355）：
   **经验事实**（本文测量）。
2. 校准后果可用人群干预前准确率描述：**描述性位置标记**（变号点两口径约 0.58–0.62
   与 0.65–0.74，只标位置、不是可移植判据；dogs 域 16 格的方向描述与 food101 拟合
   关系做了一次数量级一致性检验——合并预测带命中 14/16、分方法带 10/16，其中
   8 格为外推、2 个未命中格均为近乎不干预的 M3ID；这是**一致性检验**，
   不是预测，不据此主张阈值可移植）。
3. "标准基准的评测人群落在受益侧"：**引用性讨论**（引文献报告的基准准确率推断，
   非本文经验发现）。

## 残余结构作为开放问题

"未被纠正的错误获得比正确答案更强的确定性"在本文证据下**未获汇总确立**：逐样本
汇总统计量边界性含零，格级证据两向并存（6 正 2 负 8 超界、4 等价、11 不定，
I² = 89.2%），元回归斜率对权重口径敏感（逆方差权重 −0.023 显著、随机效应权重
+0.033 不显著、未加权 +0.075），交互项 θ = +0.061 在模型与类别聚类下显著、
在格聚类下不显著。因此"整体重标定 + 残余成分"是二成分近似描述，残余成分的
方向、成因与人群依赖性留作开放问题；其对结论的影响是：任何只调概率的后处理
都无法触达错误存量，这与第三层的使用边界一致。

## 使用建议（操作含义，不是新方法）

在模型大多答对的人群上，对比解码的置信度增量有依据，校准代价可用一次性常数校正
兜底；在模型大多答错的人群上，同样的增量变成盲目自信，校正只能修把握、修不了
错误——那里需要的是提高答对率，而不是任何输出侧的确定性调整。
变号点区间（0.58–0.62 与 0.65–0.74）可用来粗略判断自己的人群落在哪一侧，
但它只是位置标记，使用前应以小规模实测校准确认。
