# 操作层分析：概率变化与指定路径可达性

本节是纸上推导及对应实现的说明，不把代数恒等式作为未经实证的重大理论贡献。统一推导以VCD为对象；其余方法保留各自官方算子，在既有测量中比较，不把DeCo、DoLa强行写成同一个VCD公式。

## 精确的概率增量

固定图像、提示词与生成前缀。原始分数为 \(z_j\)，参考分数为 \(r_j\)，其差为 \(d_j=z_j-r_j\)。原分布为 \(p_j=\mathrm{softmax}(z)_j\)，VCD保留集合为
\[
S=\{j:z_j\geq\max_kz_k+\log\beta\},\quad\beta=0.1.
\]
它在强度 \(\alpha\geq0\) 下的分布为
\[
p_\alpha(j)=\frac{\mathbf1\{j\in S\}p_j\exp(\alpha d_j)}{\sum_{k\in S}p_k\exp(\alpha d_k)}.
\]
这说明实际概率同时受候选支持和相对参考优势影响。两者都不包含正确性标签。

令 \(P(S)=\sum_{k\in S}p_k\)，\(p_S\) 为在该集合内的归一化原分布。对于保留候选，
\[
\log\frac{p_\alpha(j)}{p_j}
=-\log P(S)+\alpha d_j-\log\mathbb E_{p_S}[e^{\alpha d}].
\]
第一项是移除候选后重归一化带来的概率变化，后两项是相对于其余保留候选的参考优势。右侧可以在读取两个分布后直接算出，不需要拟合温度，也不需要正确性标签。这是条件概率变化的精确计算，不是部署前的准确率或校准预测。

对于固定目标token，
\[
\frac{\partial\log p_\alpha(j)}{\partial\alpha}=d_j-\mathbb E_{p_\alpha}[d],\qquad
\frac{\partial^2\log p_\alpha(j)}{\partial\alpha^2}=-\operatorname{Var}_{p_\alpha}(d).
\]
其概率是否增加取决于目标的参考优势是否超过当前分布下的平均优势。二阶导非正意味着固定目标的对数概率随强度是凹函数；当最大候选改变时，不能把不同目标拼接后的曲线当成同一个固定目标。

在零强度附近还可写
\[
\Delta\log p_j=-\log P(S)+\alpha(d_j-\mathbb E_{p_S}d)
-\tfrac12\alpha^2\operatorname{Var}_{p_S}(d)+O(\alpha^3).
\]
这给出了局部曲率来源，但正式数值使用上面的精确式，不把较大强度的误差解释为定理失效。

## 温度关系的适用条件

若参考分数可以近似写成 \(r=\eta z+c\mathbf1+\varepsilon\)，则
\[
z+\alpha(z-r)=[1+\alpha(1-\eta)]z-\alpha\varepsilon-\alpha c\mathbf1.
\]
当剩余项较小且缩放系数大于1时，候选集合内表现为概率集中。能写出这项分解不代表剩余项小；更不代表每张图得到相同概率增量。代码中的局部投影只记录这一近似的数值尺度，不据此重新拟合一个预测方法。

## 从单步排序到完整名称路径

给定一个目标token \(y\)。它必须属于 \(S\)。对每个竞争候选 \(k\in S\)，选择目标要求
\[
(z_y-z_k)+\alpha(d_y-d_k)\geq0.
\]
若竞争者的token编号更小，在相等时会按argmax规则获胜，因此对应边界需要严格不等号。每个约束都是关于强度的半区间；交集为一个可行区间，也可以为空。

给定名称序列 \(y_1,\ldots,y_L\)（包含指定终止词），在每个指定前缀上分别计算条件分数。所有前缀区间再求交集。只要贪心解码采用同一个固定强度，非空交集中的强度即可逐步生成这条路径；证明直接来自逐步归纳：第一词满足，第二步看到指定第一词，于是其分数与教师强制计算相同，依次继续。

这比有限强度扫描更明确：它覆盖固定参考下所有非负强度，而不是只尝试0.5、1和2。候选支持在每个指定前缀处依赖原始分数，与对比强度无关，因此完整判定不需要搜索其他前缀。真实浮点实现仍需见证生成核对，不能只验证代数。

## 什么结论能够成立

若两个指定拼写都为空区间，可以说：在这两个拼写与指定终止规则下，该固定VCD不能生成它们。不能说它无法生成任何合理别名，更不能说模型没有相应语义知识。加入候选列表、换参考图像、改变提示词或重新训练都会改变问题，不受当前空区间约束。

若区间非空但默认强度不在其中，只能说默认强度没有覆盖该指定路径。利用真实标签选见证强度是诊断，不是可部署的改进方法。本文不把这种结果当作新的方法准确率。

## 连接纠错与评价

净准确率为
\[
\Delta A=(1-A)\,r_{\mathrm{correct}}-A\,r_{\mathrm{induce}}.
\]
这里两项分别是初始非正确和正确集合上的条件转移概率。它说明纠正机会与致错机会使用不同分母；这项恒等式不具有独立新颖性。

更重要的经验问题是：参考重加权在什么样的实际名称路径上提供足够的优势，在哪些路径上只增加现有赢家的概率。原有未变答案实验提供后者的直接测量；新增路径与证据实验补充前者的条件。固定覆盖率风险则回答这些变化是否影响采纳答案的可靠性。

对于校准，有符号平均差满足 \(\Delta(\bar c-A)=\Delta\bar c-\Delta A\)，但分箱ECE还依赖置信度分布和分箱变化。即便每个样本加同一常数，也不能仅凭准确率预测其符号。该部分作为解释，不再提出通用变号阈值。
