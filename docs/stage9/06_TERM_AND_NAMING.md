# 术语、对象与命名

本文统一使用“类别子集”“高/低准确率类别”“分布锐化”“概率集中”“两组校准变化之差”“纠正率”“致错率”“原有错误”。不用社会调查用语代称模型的图像类别分组，不给已有统计量另起口语名称。

纠正率定义为初始非正确样本中变为正确的比例；致错率定义为初始正确样本中变为非正确的比例。图中同时显示两者占全部评测图像的数量比例，避免两个不同条件分母被直接相减。净准确率变化等于纠正数量减致错数量再除以总样本数。

“未变答案”在旧实验中遵从其既有文本规范化与首token一致定义。新路径分析的“相同序列”则要求每个token及指定终止词一致，两种对象不得混称。名称序列概率是实际解码分布下的token概率乘积，不是名称正确的概率。“预测不变”也不代表模型内部状态完全不变。

“指定名称可达性”专指：固定模型、图像、提示词、参考输入、候选约束、贪心规则及名称token序列，是否存在允许的对比强度。“知识可及性”“知识缺失上界”不用于命名这项测量。教师强制只是读取指定前缀下的分数；自由生成见证才检验这条路径是否实际出现。

方法名称固定为VCD、M3ID、DoLa、DeCo、SID。内部程序标识可用既有`vcd`、`m3id`等键；显示文本采用正式名称。历史本地变体不进入新分析及主要表格。

模型显示名：Qwen3.5-4B、Qwen3.5-9B、LLaVA-v1.6-7B（Mistral骨干）、InternVL3.5-4B。既有`llava16`只是文件内部键，不解释为参数规模。

数据名称使用Food-101、Stanford Dogs、POPE-COCO。图像退化称“短边64像素条件”“短边32像素条件”，不称对象知识改变。POPE的random/adversarial是官方负例采样标签，不与模型实际准确率等级混用。

正文不使用实验内部代号代替概念；公式中的变量在定义后给出一句解释，后续自然语言说“初始排序差距”“相对参考优势”“选择性风险”等概念，而不是连续复述符号。方案、预登记和运行报告都执行此规范。
