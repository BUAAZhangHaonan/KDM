# 附录A.1原始配置补充

Food-101图像取自官方训练与测试划分的合并类别池（Hugging Face分别命名为train与validation），按类别名排序并使用Python random.Random(42)逐类打乱，每类前48张中的前24张进入开发候选池、后24张作为评测集；404题开发集依冻结样本清单从前者每类选4张，与2,424题评测集互不重叠。

VizWiz的512题取自官方val划分，先按原图像文件名SHA256前八位的整数值模5确定项目划分（余数为0进入dev，其余进入eval），再从eval池依冻结样本清单按可回答性分层选取166题不可回答与346题可回答。

十次独立试答开启采样，temperature=1、top-p=1、top-k关闭（vLLM设为−1），生成上限为32词元；第r次试答（r=0,…,9）的随机种子设为stable_seed(sample_id, model, r)。

三句话可直接补入附录A.1。主评测的温度0、top-p=1与32词元上限另记为主评测设置；十次试答使用上述采样参数。

来源核对：4,848个Food原始文件名、类别与分组身份和当前清单完全一致；404题为101类各4题且与eval零交集；512题的官方可回答性计数为166/346。两份子集的可复现身份为冻结的有序样本ID清单，见同目录CSV及SOURCE_INDEX.csv。

Food原始取样seed=42；配对Bootstrap seed=20260929；本次100题A100计时子集的seed单独登记在成本结果包。
