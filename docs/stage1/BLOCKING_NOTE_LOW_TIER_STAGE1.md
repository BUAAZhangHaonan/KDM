# 阻塞说明:低频类别组可用图像不足三百张

按任务书第六节("若扩大候选池后低频类别组的可用图像仍不足三百张……按第十二节处理并明确上报")与第十二节(不允许静默兜底、不得自行替换数据集),现将情况正式上报如下。

## 缺少什么

按任务书规定的入选条件(目标对象明确可见且占据主体位置、该图在所属频率档下只包含一个目标类别、图像可下载可解码),低频类别组(`frequency == 'r'`)的可用图像为 **97 张**(验证集 8 + 训练集 89,下载成功率 94.7%),低于 300 张门槛,更低于每组 600 张的目标。

## 为什么无法继续扩大(结构性原因,非流程故障)

LVIS v1 的频率档是按**全数据集出现图像数**定义的:`r`(低频)类别每类在整个 LVIS(train+val 合计约 16.4 万图像)中只出现在 1–9 张图像里(标注文件 `image_count` 字段可直接验证,337 个低频类别)。因此低频图像的全集本身就只有约 1,784 张(val 322 + train 1,462,实测统计)。在这之上叠加任务书的三条入选条件后,选择漏斗实测为(train 标注,val 同口径):

| 步骤 | 剩余图像 |
| --- | --- |
| 含至少一个低频类别标注 | 1,462 |
| 该图低频档下只有一个类别 | 1,431 |
| 目标实例为全图最大标注(主体位置的确定性代理) | ~300 |
| 且实例面积 ≥ 图像面积 15% | **95** |

即使把"主体位置"放宽为"与最大实例共同主导(面积≥其一半)"、把面积门槛降到 5%,全集也只到 279 张,仍不足 300。也就是说,**不足是 LVIS 频率定义的结构性结果**,任何进一步放宽都将把"背景中的小物体"当作主要对象,直接损害命名任务标准答案的有效性,属于以降低数据质量换取数量,不予采用。

## 尝试过的来源

1. 任务书给定的验证集标注(已下载并核实,md5 `87734a7f895990b9552075d7ce723e27`)→ 低频候选 8 张。
2. 任务书给定的训练集标注(已下载、zip 完整性校验通过)→ 低频候选 95 张(合计 103,下载成功后 97)。
3. 量化漏斗(上表)证明任何合法放宽都无法达到 300。

未尝试、也不采用的方案:换用其他数据集(任务书明令禁止);放宽到共同主导+5% 面积(279<300,且引入标注噪声)。

## 对本研究的影响与继续执行的决定

- 主实验仍按两组各 n=97 继续(两组规模相同,逐样本配对比较照常),**不视为任务失败**,但结论的统计功效受限:低频组比例差的配对置信区间宽度约 ±10–13 个百分点,小于该量级的效应无法与零区分。该限制在 docs/stage2/CONCLUSIONS.md 的"适用条件与限制"一节再次声明。
- 该决定只涉及样本量,不改变任何入选标准、判分规则或预先声明的判定条件。
- 若审阅者认为 n=97 不足以支撑结论,本文档即为提前上报的阻塞记录,而非事后解释。
