## 第三项的条件方向

令候选对为答案 token a 与弃权 marker 首 token b；令正常/扰动无引导边际为 c/r，有引导边际为 g/h。原参数 alpha=1。

- 自然视觉项：c-r。
- 正常指令增量：g-c。
- 参考指令增量：h-r。
- 交互 E=(g-c)-(h-r)。
- IP-guided 的答案对弃权边际差为 -E。

因此 E<0 时去掉交互会提高答案相对弃权的边际，E>0 时会降低。该方向是同一前缀、同一候选支持下的局部代数关系；完整回复的语义弃权仍用已接受评分，不能从单个 marker token 推断。

代表面板实际有 471 个答案/marker 首 token 候选对：E<0 为 91，E>0 为 378，近零为 2。两候选都在 guided 支持内的 177 对中，分别为 44、132、1；两者同在正常与 guided 共同支持的对为 0。支持集合必须单列，不能把这些比例当作实际弃权变化率。

代表首位 native/IP 的 argmax 不同为 222/505；将 native 也限制到 guided 支持后为 107/505；guided/IP 为 88/505。共同支持为空有 52/505。这里报告实际支持与共同支持两种结果，未将首 token 差异包装成回答质量结论。
