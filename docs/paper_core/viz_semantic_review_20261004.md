# VizWiz native additions: semantic authority, 2026-10-04

This update applies only to the newly generated native DoLa, DeCo and applicable original SID outputs on the fixed 512 inputs. Frozen earlier scores are unchanged.

The first `batch002_03` and `batch002_05` outputs were generated by keyword rules and first-sentence extraction while reported as Luna semantic annotations. They are excluded. `batch002_01` also contained incorrect row-index labels; root independently read all 200 full QAs and saved separate corrections. Original records and writer scripts are preserved as evidence.

Replacement small batches carry explicit per-QA decisions. Complete question and generated answer are shown to the annotator; ground-truth answers are absent. Root checks semantic boundary cases and a fixed every-tenth sample. Where a review finds batch-wide mapping problems, the affected batch receives complete review. Scripted JSON validation alone is not semantic review.

`annotation_authority.json` explicitly lists accepted source files and their hashes in precedence order. Unlisted and rejected outputs never enter scoring. Outstanding `needs_root` decisions remain pending. Root corrections preserve the actual Luna source path, hash and row, and identify the root author separately.

The finite CPU scoring entry also accepts the immutable original bytes covered by a verified handoff seal. This includes the last partial part at an input boundary without manufacturing a new generation completion receipt. It verifies the source identity, raw hash, sample subset, seeds, finite probabilities and original task keys. Repartitioned generation does not duplicate finished inputs.

Validation: a real CPU snapshot scored 5,398 newly sealed rows, including the six-row Qwen2.5 handoff part, with unique task keys and original provenance. It reported 2,159 unresolved QAs rather than counting them as completed labels. Only complete 512-row conditions with all final spans and abstention decisions enter result tables.
