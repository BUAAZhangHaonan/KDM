# 五模型研究材料审阅指南

## 审阅目标

请从研究问题、方法新意、实验公平性、评分有效性、统计可靠性和论文论证六个方面审阅本研究。请给出证据支持的主张、关键问题、优先修订项及可执行的论文结构建议。优先使用现有完整结果开展核查；需要补充实验时，请说明它具体改变哪项结论及最小实施范围。

## 当前交付

- 五模型：Qwen2.5-VL、Qwen3.5-4B、LLaVA-v1.6-Mistral、MiniCPM-V2.6、Gemma3-4B。
- 正式回答：853,248条，352个完整条件，每条件2,424个eval样本。
- 独立试答：242,400条，对应24,240个模型—问题对，每对10次。
- 主指标：规范主菜类别匹配、完整抽取名称敏感性、弃权行为；三个字段待定均为0。
- 两套参考GT：每套24,240行，分别报告已接受参考与统一规则参考。
- 主统计：372组配对比较；按101个Food-101类别聚类，2,000次配对bootstrap。
- 简单弃权控制：200个派生条件、40组指令方法对照。
- 英文论文已完成核心结果稿，当前进行外部审阅。补充机制测量保留为后续研究。

## 重点问题

1. 完整矩阵中，哪些现象在多个模型与提示条件下稳定出现？哪些结论需要保留具体条件限定？
2. 40组指令保持对照中，26组满足准确率非劣，12组合理弃权保留改善，2组同时满足。请结合配对区间、分母大小及多重比较讨论这两组证据的力度。
3. 简单保留原始弃权的控制达到原合理弃权100%保留。请评估指令保持方法额外获得的正确率、覆盖率及相应弃权取舍。
4. 当前Food-101主评分使用明确主菜中的101规范类别词，保留烹饪/风味限定；完整名称等值另存敏感性。请核查修饰、主配菜、同级候选、否定和复合菜名的处理是否一致。
5. 参考GT使用候选排名与十次独立回答构造。请审阅其研究用途、抽样预算、模型依赖性及已接受/统一规则两套GT之间的变化。
6. 检查direct基线、4种主提示、参考提示组合、reference-guidance removal、SID适用模型、32-token限制及dev/eval划分的比较公平性。
7. 区分解析推导与当前行为实验的实测证据，评估论文最合适的主问题、贡献表述、图表组织和标题。
8. 给出按影响排序的审阅意见，每项附文件/表格/条件、具体证据及修改建议。将已有数据可完成的修改与新增测量需求分别列出。

## 资料身份

当前评分与方法比较以本指南链接的最终文档、代码和结果表为依据。最终验收结论见 `outputs/records/main_results/score_acceptance.json`、`reference_gt_acceptance.json`、`analysis_acceptance.json`和`copy_control_acceptance.json`；生成器回执保留各自写入时的阶段状态。`context/ORIGINAL_RESEARCH_OBJECTIVE.md`在审阅压缩包中保存用户最初任务书原文，用于研究目标沿革对照。原始任务书覆盖16模型和Food-101/VizWiz；当前核心论文的正式方法结果覆盖上述五模型Food-101面板，16模型普查另保留完整资产。

名称抽取与行为标注由规则、实际Luna判断及root对主指标疑难的审阅共同完成，作者与来源分别记录。审阅案例文件收集边界与分歧处理，适合核查具体规则；总体质量估计应另按明确抽样方案计算。

审阅包保留仓库相对目录，附论文、核心文档、完整聚合表、两套GT、全部最终图、评分/统计实现及主要验证回执。样本级大型原始流、图像、权重与历史档案保存在项目主库，包内清单记录其定位和身份。
