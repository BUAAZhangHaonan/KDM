## 1. 第一部分判据（计算前冻结；全部使用第六阶段缓存记录与首 token 分布）

样本口径统一：评测半区、既定分组、答案未变样本（归一化文本相同且首 token 相同），
置信度按第六阶段口径（各配置最终分布、截断重归一化之后）。

### 1.1 分格尖化一致性（决定性）

对每个（模型 × 组 × 方法）格（共 32 格，答案未变样本数 ≥ 20 者参与判定）：

- 干预分格差 δ = 平均增量(一直错) − 平均增量(一直对)；其中"一直对/一直错"按
  直接解码与干预解码 outcome 是否均为 correct / 均非 correct 界定（弃权计入非 correct）。
- 温度尖化对照分格差 δ_对照：同一格、同一样本子集上，用第六阶段拟合温度 T 从直接
  首分布算出的对照增量，按同样分格取差。
- 配对自助（B=2000，种子 20260916）：δ 与 δ_对照 各自的 CI，以及
  Δ = δ − δ_对照 的 CI（样本级配对：每样本两增量同进同出）。

**判定（格级，二值）**：δ 与 δ_对照 同号 且 Δ 的 95% CI 含 0 → 该格的分格模式
可由尖化解释；异号，或 Δ 的 CI 不含 0 → 该格存在尖化解释不了的选择性结构。

**分支规则（冻结）**：设可解释格数 E、结构性格数 R。若 R > E，主线按强版撰写
（第一层保留"未被纠正的错误获得更强确定性"为独立发现；第二层写"方向与尖化相反的
残余成分"）；若 E ≥ R，主线按弱版撰写（第一层只写"抬升覆盖全部样本、纠错只覆盖
少数"；第二层维持"近似整体重标定"）。

### 1.2 分布级一致性指标

每个可匹配格（干预平均增量 ≥ 0.04，与第六阶段排除口径一致并另行全格报告）：
- 逐样本增量的 Spearman 秩相关（干预增量 vs 温度对照增量，同一未变样本集）；
- 两个增量分布的 Wasserstein-1 距离。
与 1.1 并列报告，不单独构成判据。

### 1.3 强度正对照（旧 MIB 变体）

复用 q4b/q9b 主记录中的 MIB 行（评测半区两组；既有记录不足则按原超参重跑）。
呈现：准确率、ΔECE、救回率、置信度增量，与忠实四方法并列成表但**单独分区**，
标注"模糊图分支 + 线性衰减权重的本地变体，不是任何已发表方法"。用途：演示
"纠错收益足够大时校准符号可以翻转"。

### 1.4 双口径计数

机制判据计数同时给出：全 32 格口径、排除低分辨率格（干预平均增量 < 0.04，
温度网格下界）后的口径。排除理由随表注明。

### 1.5 偏移漂移量化

逐格计算 漂移 = 开发半区偏移 − 评测半区未变样本平均增量；报告均值、标准差、
范围，并与四格非均匀合并为一条陈述：常数偏移只是近似。
