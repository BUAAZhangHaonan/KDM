# 剩余四模型：有限真实问答标注合并

本轮只接收完整问题与完整回答完全相同的行为判断。显式来源清单指定修正优先级，原始标注、历史裁定与作者身份保留；规则、Luna 与 root 判断分别记录。没有实际模型阅读证明的脚本产物保持 preliminary。

`compose_semantic_authority.py` 读取有限互斥队列、已核验的实际标注及有限 root 修正。它只适配已存在的 span 字段和布尔别名，不从目标答案或完整回复自动创造短答。缺少作者身份、实质答案 span、未决标志或冲突时输出待审项。相同优先级的冲突拒绝合并。

`apply_viz_reviews.py` 将已闭合的精确 QA 逐条连接到不可变评分。VizWiz 的答案质量使用实际提取 span 与官方十个答案计算连续分数；完整原回复的官方分数另外保留。弃权与 invalid 的答案质量为零，未知项继续为空。Food 评分、参考、条件、输入与来源保持逐对象相同。

新分片的 `score_received.py` 验证新权威文件的回执与闭合数；显式的新精确 QA 裁定优先于早期推断，同时在新记录中保留早期裁定来源。修正只作用于本轮新增结果。

实际验收来源：

- `outputs/supplemental/remaining4/semantic_authority_20261001_2035_v3/receipt.json`：10,907 个唯一 QA，10,907 闭合，未决 0。实际来源为 Luna medium、有限 root 判断和四条已登记的空回复规则；未知 callID 未填造。
- `outputs/supplemental/remaining4/received_scores_20261001_2040_closed_viz/receipt.json`：99,796 条唯一生成键；51,616 个 Food 对象完全相同；48,180 个 Viz 对象的原回复官方分数未改变。
- 新闭合判断应用到 12,184 个成员。余下 16,975 个唯一 Viz QA、24,324 个成员保留未决，由新的互斥标注队列接续。

以上为已接收分片的实际验收，不表示全模型或全条件完成。代码不初始化 GPU，不重新打开活动 raw，不修改原始五模型的冻结产物与论文正文。
