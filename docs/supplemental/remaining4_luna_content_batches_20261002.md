# 四扩展模型：完整问答批量标注

本轮先按冻结的提取与评分规则、字符匹配和已决完整 QA 精确复用关闭确定项。明确错误且无弃权的回答可以直接计零；只有影响主答案、语义弃权或参考连接的边界需要真实 Luna。Food 对已提取主菜做 101 规范名称比较，不能在整段回复里按目标挑菜名。VizWiz 保留官方连续共识评分，Luna 提取回答内容和行为，不按官方答案选择 span。

`workflows/supplemental/remaining4/prepare_luna_content_batches.py` 仅包装已通过 receipt 的未决问答，生成互斥 owner 与模型 payload。它不生成标签或答案 span。每批至多 250 条，完整显示问题和全部已生成回复，记录来源 SHA、行与成员；不截断、不给模型暴露 GT。本次实测先使用短回复队列（至多 64 字符、无换行），较长回复仍是独立未决项。

当前子代理接口没有设置 32K 上下文上限的选项。28,672 UTF-8 bytes 是本入口的内容预算，不能写成实测 token 数。问题、宿主指令、历史和逐条判断输出也占上下文。本轮实际 provider usage 包含这些开销，不能声称总上下文是 32K。

2026-10-02 的第一组两批：各 250 条，payload 21,191 / 20,775 bytes。真实 `gpt-5.6-luna`、`medium` 工具输出均完整显示 0–249，未截断。任务到最终逐条 JSON 用时 118.488 / 131.247 秒；读完到最终输出 103.442 / 107.502 秒。实际最终调用 input 为 45,646 / 45,574 tokens，output 为 8,436 / 8,748 tokens。它们是含宿主开销的 provider 计数。

原始模型输出和实际工具事件保存在 `outputs/supplemental/remaining4/luna_content_batches_20261002_0100/true_luna500_provider_20261002_0055/`。独立绑定与追加 root 复核保存在 `true_luna500_actual_20261002_0110/`：实际模型 500 QA，root 有限读 83 QA，另存 32 条裁定。原始判断没有覆盖。新增联合目标 456 QA，另外 44 QA 已在原范围内；每个来源与完整问题/回答精确连接。

实际应用回执 `received292541_20261002_0120_actual500/receipt.json` 通过：292,541 唯一生成键、Food 177,333 个对象保持原值、VizWiz 115,208 条。已到达队列的 VizWiz 未决由 35,312 降至 34,812 个完整 QA，由 52,075 降至 51,108 个成员。冻结官方原始分数、图像和参考标签均未改变。authority 的 `closed_QA` 表示来源闭合，其中仍有质量或行为 hold；不能把它误称为全部内容标注完成。

第二组两个互斥 250 QA 也已返回真实逐条 JSON。原始 provider 输出保存在 `luna_content_batches_20261002_0120/true_luna500_provider_20261002_0142/`，仍待有限复核与应用，不计已验收。任务到 JSON 为 103.183 / 104.098 秒。本轮只据短回复计算纯模型处理速率，不用文件写入耗时、不对未生成的未来回复作已完成统计。

入口验证使用实际不可变队列：第二组 payload 20,820 / 20,656 bytes，排除前 500 与已有 20 个 owner 后互斥；完整内容未截断、标签生成零、GPU 初始化零。源 SHA 只计算一次，包装 500 QA 实测 1.044 秒。原先逐行重复读源文件计算 SHA 的版本保留在第一组的 `preparation_source_v1.py`；该重复 IO 已修正，不涉及任何模型参数或科学标签变更。

新增 46 个 Food 边界 QA 已经由真实 Luna 返回、12 个 root 裁定追加，实际覆盖 63 个来源绑定成员。`received292541_20261002_0130_food46_actual500/receipt.json` 通过，Food 主正确性与 literal 未决均为零；参考连接回执 `received292541_20261002_0140_reference_bound/receipt.json` 通过，177,333 个已到达 Food 成员接入冻结 GT，保留原有 159,831 个参考连接，VizWiz 115,208 个对象保持原值。只有已接收的 17 个 Food 条件覆盖完整，不能写成四模型全部方法已经验收。

其中一条模型返回的 QA SHA 抄写错误，完整问题与回复逐字匹配不可变源；绑定使用源计算出的完整 QA 键，原错误 SHA 与原判断另存，未改文本或科学标签。这也说明批量输入用稳定整数索引、由 CPU 回填完整来源比要求标注人复制长 SHA 更可靠。
