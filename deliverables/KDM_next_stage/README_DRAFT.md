# KDM：免训练视觉语言解码中的概率变化与错误纠正

KDM是一项分析型研究，考察VCD、M3ID、DoLa、DeCo及补充的SID如何改变视觉语言模型的答案与解码概率。核心问题是：一个以减少错误为目标的输出干预，在哪些条件下纠正答案，在哪些条件下只改变已有答案的确定性。

## 已完成的证据

项目已完成八阶段实验。主要任务为Food-101开放命名，模型为Qwen3.5-4B、Qwen3.5-9B、LLaVA-v1.6-7B（Mistral骨干）、InternVL3.5-4B；Stanford Dogs提供跨域补充。高、低准确率类别由独立图像半区上的实测命名表现确定，不是对象知识有无的标签。

在第六阶段忠实实现结果中，32个主要组合的未变答案平均置信度增量均为正，且名称序列概率也显示相应变化。错误纠正与原有正确答案被改为非正确同时存在。固定提交的高准确率子集14/16个组合准确率下降。概率与正确性的匹配还随类别子集改变，因此校准变化需要与净准确率分别解释。

项目不声称输出干预不可能恢复任何知识，不用某个准确率阈值预判所有校准后果，也不把无显著的残差差异解释为机制完全等价。历史阶段报告保留探索过程；当前有效主张以直接数据与最新论证文档为准。

## 第九阶段计划

新增工作限定为：复用四模型逐样本缓存分析纠正/致错和固定覆盖率风险；在两模型、同一图像集合上改变视觉证据；计算VCD对指定名称路径的连续强度可行区间并核对真实生成；使用同一批POPE图像提供问题采样方式的任务参照。

第九阶段的实际完成状态和新结果应在运行后写入`docs/stage9/RESULTS.md`。此README草稿不把尚未运行的第九阶段结果写成发现。
