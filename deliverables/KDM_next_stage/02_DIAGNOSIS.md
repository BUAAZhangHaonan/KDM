# 客观诊断：现在有什么，缺什么

## 当前证据能够支持什么

在所读固定提交中，四模型、两类子集、四种方法共32个组合，未变答案的平均置信度增量都为正。设置级均值的普遍性不等于每一个样本均增加。真实表格还显示，高准确率子集14/16个组合的准确率下降；提示词中的13/16与该提交不一致。本包使用可逐项核对的14/16，同时保留差异记录。

对于 InternVL3.5-4B 与 DoLa，高准确率子集由511/600正确变为413/600正确，下降16.33个百分点。其中18个原有错误被纠正，却有116个原有正确答案变为非正确。对于 LLaVA-v1.6-7B 与 VCD，对应数量为20个纠正、55个致错，准确率下降5.83个百分点。这些不是“置信度变坏”的替代指标，而是真实的净准确率损失。其来源见[S1]与样例表。

另一方面，低准确率子集的多数结果没有表现出普遍的净准确率下降。因此，不宜把“简单数据都受益、困难数据都受损”作为已成立事实。尤其不能再把低准确率直接解释为模型没有相应知识。

## 五个问题的结论

### 意义问题

如果任务确实只评价全部输入上的准确率，而且干预使其提高，那么该项收益成立。单独发现剩余错误的概率增加，不能抵消这一事实。概率变化只有进入实际决策才构成额外后果：例如选择同样数量的高置信度答案时，错误是否更多；或者原有正确答案是否被修改为错误。

本轮把“然后呢”落实到两个已有定义的量：全输入上的净准确率，以及固定覆盖率的选择性风险。前者已经有值得解释的负向结果；后者须由缓存分析决定。若固定覆盖率风险不升高，只讨论概率尺度和校准，不写成选择性回答受损。不能以干预后套用原始固定阈值的失败代替固定覆盖率比较。

### 对比与门槛问题

纠正与致错的交换不是新发现，VCD_Analysis的4.4节已经直接测量这两类变化。未变预测的置信度增加也已经出现在测试时适应的校准研究中。KDM缺的是一个在自己的任务内有可验证后果的解释：固定参考与候选支持究竟允许哪些名称路径，以及理论判定与真实生成是否一致。相关工作逐项关系见03文档。

### 深度问题

应当从真实算子推出对数概率增量与连续强度的可行区间。它不需要假定参考分布等于均匀分布，也不需要把所有变化强行近似成同一温度。一个恒等式本身不是重大理论贡献；它作为分析工具，必须揭示现有模型中实际存在的可达性结构，并用独立自由生成验证。

### 初衷与补救问题

在当前黑箱行为设定下，没有一个有限的命名或闭集测试能完整证明“模型根本不知道”。可操作的问题应当缩小为：在固定参考、候选约束、生成预算和指定名称路径下，是否存在非负对比强度使其生成。空区间回答的是这条路径在这个算法族中不可达。

原图正确、退化后错误是一种可观测的视觉证据响应。恢复原图可以恢复原先已观察到的正确输出，但这部分100%恢复由子集定义决定，不能作为新的补救效果。候选提示可测试答案在额外语言约束下能否恢复，也不能从一次成功推断原模型一直拥有完整对象知识。本文不交付普适纠错方案；建设性落脚点是明确哪些运行结论可信，避免对不可达的指定路径继续增加对比强度。

### 标题问题

“When Contrastive Decoding Makes Errors More Confident”准确、直接，可以保留为工作标题，但单靠这句话已不足以与近期工作区分。最终标题应由新增路径与选择性风险结果决定，而不是预先把二者写成发现。三个备选见07文档。

## 两个假设的判定

| 假设 | 判断 | 本轮如何检验 |
|---|---|---|
| 原论文因数据简单而获益，困难样本因缺少知识而无法纠正 | 整体因果链不成立；原论文任务与开放命名不同，现有高准确率子集反而经常下降 | 同图像退化检验视觉证据因素；POPE同图像两种负例采样检验原评价设定中的纠正/致错。不把这两项升格为知识缺失的因果检验 |
| 准确率交换、知识可及性上界、事先预测校准三者合并 | 只保留第一项；第二项改成指定路径可达性；第三项改成由实际分布计算概率变化 | 路径区间使用完整词表与固定参考；校准需要正确性标签，无法仅凭准确率事先确定 |

## 对此前判断 A—H 的逐项处理

| 判断 | 结论与本轮处理 |
|---|---|
| A：把近似锐化从观察变成推导 | 部分采纳。采用精确重加权分解，不把温度近似的条件当作已验证事实 |
| B：保序概率集中与排序改变条件 | 采纳，推进为指定序列全路径的连续可行区间 |
| C：删除准确率单变量部署判断 | 采纳；跨域预测带覆盖不等于方向判断能力 |
| D：偏移撤销可能撤回校准收益 | 采纳，保留一张附录图即可，不作为新算法 |
| E：同图像退化改变视觉证据 | 采纳；类别标签不变并不能保证模型内部所有影响不变，只能解释输入干预的效果 |
| F：纠正率随可及性单调 | 不能作为先验结论。探针操作化不稳定，本轮改为明确路径的区间；无需再次报告潜在知识比例 |
| G：更强强度与多方法叠加证明救不了 | 不采纳有限网格证明普遍不可能；使用连续不等式判定固定VCD路径。叠加方法改变算法，不加入 |
| H：差异落在解码操作层面 | 采纳，但公式之外必须给出实际样本结构和真实生成验证；名称概率本身不足以构成差异 |

## 论文主张与后果

第一条主张是“概率增加与纠错具有不同条件”。其后果是概率变化不能单独证明对象识别改善，读者应检查候选排序及实际纠错。第二条主张是“固定参考限制指定名称的生成路径”，须等待新结果；它的后果是该路径不能靠持续增加同一对比强度解决。第三条只在固定覆盖率检验通过后成立：“部分干预让相同数量的自动采纳答案包含更多错误”；其后果是准确率收益与自动采纳可靠性需要分别评价。

这三条中，前两条形成主要故事，第三条提供决策后果。若第三条不成立，不追加新阈值寻找负面结果。若第二条缺少非平凡的实证内容，不把数学恒等关系单独包装为机制发现。
