# 可视化规范与本包图的用途

## 设计约定

使用独立单坐标图，每幅图回答一个明确问题。双栏图宽约6.8—7.2英寸，正文缩放时先保持可读字号，不依赖超小脚注。当前默认DejaVu Sans，PDF采用可嵌入矢量文本；不分发字体文件。数据图输出240dpi PNG和矢量PDF，图中所有点、线、区间可追溯到CSV或数学例子。

颜色：纠正用低饱和青绿`#2E827C`，致错用低饱和砖红`#C35B4E`，参考文本用深蓝灰`#243344`，VCD用蓝`#4263A2`，M3ID用紫`#8B63A8`。对类别子集的颜色与方法的形状分别编码；不能在同一幅图中令一种颜色同时代表两套含义。避免渐变、3D柱体和大面积装饰底纹。

概率与准确率变化用百分点，原概率或分数在来源CSV保留未缩放值。纠正与致错图的柱子共享全部图像分母，净变化用独立菱形；不把不同条件分母的两个比例画成可直接抵消的数量。

## 已执行的七个绘图函数

| 输出 | 数据性质 | 任务 |
|---|---|---|
| `real/01_error_exchange` | 真实汇总转录，16个高准确率组合 | 纠正与致错分别是多少、净变化为何为负 |
| `real/02_confidence_tradeoff` | 真实汇总转录，32组合 | 答案未变时的置信度变化并不要求准确率提高 |
| `real/03_offset_reversal` | 真实4条校准轨迹，选择性示例 | 同一方向的撤销操作能撤回代价，也能撤回收益；附录使用 |
| `illustrative/04_reachable_intervals` | 三token精确数学例子 | 看懂始终保序、越过初始差距和被支持集合排除 |
| `illustrative/05_risk_coverage` | 合成逐样本记录，经真实分析代码得到 | 核对风险曲线、同分边界与图例；不是新实验结果 |
| `illustrative/06_evidence_control` | 显式给定的合成设计示例 | 核对证据强度曲线的版式；不是新实验结果 |
| `illustrative/07_name_reachability` | 显式给定的合成分类记录 | 核对指定路径类别组成的版式；不是新实验结果 |

所有示例图均有来源标记。后三张模拟图中的数值没有预测含义，不参与论文结论。真实模型运行完成以后，使用相同函数读取新CSV并取消`--fixture`；不得手工删去示例标记、保留模拟数据冒充结果。

## 如何重生成已交付图

```bash
python code/viz/stage9_figures.py \
  --package . \
  --risk-csv data_sample/synthetic_risk_coverage.csv \
  --evidence-csv data_sample/synthetic_evidence_accuracy.csv \
  --reachability-csv data_sample/synthetic_name_reachability.csv --fixture
```

以上命令已经实际执行。真实新结果的调用方法见执行提示词。代码只有一个绘图模块，没有附带未经运行的候选绘图脚本。

## 不采用的图

不用多张仅更换方法名的置信度直方图，不用面积难以比较的环形图，不把无关稳健性结果拼成一张大型矩阵。没有真实新结果时不画带“结果”标题的占位图。置信区间需要由实际配对分析产生，不能由汇总端点反向编造；当前真实准确率交换图显示数量，不展示尚未计算的置信区间。

## 检查项

既检查PNG，也渲染PDF检查字体、边界、图例及标注。已修正首图标题与图例重叠，并重新输出全部图。验证报告记录每个函数的输入、数据性质和输出路径。论文最终排版仍需按栏宽检查一次，但不需要重新设计每张图的字体和色彩。
