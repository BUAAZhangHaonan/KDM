## 2. 本轮不新增公开数据集：硬约束与理由

本轮**不引入任何包外数据集**，不把 Food-101 替换为其他公开难数据集，不追加"更难"的评测集，不新装模型。

理由：

1. 现有证据已与"数据集越难、对比解码越无法纠正"的方向相冲突：高准确率子集（即容易的一侧）14/16 个组合净准确率下降。再引入难数据集，只会把"难度"与"类别知识覆盖""提示词与评分器差异"混在同一处，无法归因。
2. 第一阶段在 LVIS 上已经给过同类教训：按数据集自带属性分组会导致分组无效、被解释量没有空间、样本量不足。换数据集会让这三个问题原样重演。
3. 第四阶段已证明检索失败占比是操作化的函数（同一现象在 4.6%、25—76%、71—93% 之间随口径变化）。任何跨数据集的占比比较都不具备可解释性。
4. 本轮主问题是"分数变化与实际答案排序的关系"。它在同一批类别、同一提示词、同一评分器下即可回答；难度只是它的一种语境，而语境由同图像退化提供即可——图像身份、类别标签、提示词与评分器全部保持不变，只有视觉证据强度变化。
5. 在一个月的窗口内，替换数据集是唯一能够吃掉一周、却不产生主线结论的动作。

需要明确：包内已列入的 **POPE-COCO 同图像参照继续执行**。它连接的是原方法的评价设置，不构成新增难度数据集。除此之外不下载新的评测集。

若实验二的退化操作落在有效区间之外（见 3.1），结论是"本轮不具备检验该假设的条件"，**不得**以新增数据集的方式补足。

## 3. 两条新增要求

### 3.1 退化条件的有效性先判定，无效就如实收口

在执行实验二的正式运行之前，先用原图与两个退化条件下的**直接解码**结果做一次有效性判定，并把判定写进 `RESULTS.md`。

判定规则：

- 若短边 64 或短边 32 的直接解码准确率落在 [0, 0.10]，或三个条件中任意两个在类别配对区间上不可分辨，则该退化操作在本模型上不构成有效的证据强度操纵。
- 此时如实报告该结果，并在 `RESULTS.md` 明确写出："本轮不具备检验'数据集难度'假设的条件。"
- 不得为此更换退化种类（改用模糊、遮挡、噪声等）、不得追加第四个条件、不得因为曲线不好看而调整退化参数。上述行为都属于以结果为导向的防御性调整。

若判定有效，按预登记报告三个条件的准确率、纠正数量、致错数量与跨条件配对效应；正文只使用曲线本身，不额外展开机制解释。

### 3.2 可达区间必须做参考噪声的稳健性检查

包内的区间判定是对**一次参考噪声实现**的精确计算。参考分支由随机噪声采样产生，区间也条件于该次实现，仅报告一次抽样的区间不成立。

要求：

- 每条路径在 **3 个噪声种子**下分别计算区间（使用包内既有的逐样本种子规则加上固定偏移，不改动原实验使用的种子）；
- 报告三个种子下的区间端点，以及"区间是否为空"这一结论在三种子间是否一致；
- 只要出现区间为空与区间非空在不同种子间翻转的路径，一律单列为"不稳定"，不得作为主要结论使用。

成本：路径数不超过 800，因此不超过 2400 次区间计算，全部是在读取已有前向分数之后的 CPU 计算，**不需要增加任何自由生成次数**；见证生成仍只在通过稳健性检查的路径上进行。

摘要、正文与主要表格不得使用未通过稳健性检查的路径。若通过检查的路径少于全部路径的三分之一，按包内 02 文档的条款把几何结果降级为附录材料，并在总结中如实说明。

## 4. 主线的收束

**一句话故事（正文只讲这一个）：** 以减少错误为目标的解码干预，可以在答案没有变正确、甚至更多原有正确答案被改坏的同时，让输出更确定；能否把答案改对并不由强度大小决定，而由初始排序差距与相对参考优势是否同号决定——当目标不在候选支持内、或排序约束彼此不相容时，任何非负强度都无效。

三条主张的层级必须显式写出，不得混排：

- **主张一（机制层，先写）**：概率增加与实际纠正满足不同条件。
- **主张二（受控证据层）**：在独立类别分层与同图像证据干预下，联合报告纠正、致错与未变答案的概率变化。
- **主张三（决策后果层，条件性）**：仅在固定覆盖率风险检验通过后单列；不通过则明确写出该主张未获支持，**不得用其他指标替代，也不得转去更换阈值寻找负面结果**。

**结论要落得更深，需要给出下面的分类，而不是只给区间数量或占比：**

- 区间非空且包含默认强度 → 默认强度已足够，问题不在强度；
- 区间非空但不包含默认强度 → 属于强度选择问题；
- 区间为空，因目标不在候选支持内 → 属于支持集合问题；
- 区间为空，因排序约束不相容 → 属于参考构造问题。

要求报告四类的路径计数（并写明所用的操作化），同时声明该分类不表示对象知识的有无。这四类分别对应不同的后续动作，是本文可操作的落点；不要退回"占比是多少"的表述。
