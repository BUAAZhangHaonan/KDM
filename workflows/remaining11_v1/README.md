# Remaining-model scoring and Qwen3-VL completion binding

`qwen3vl_closed.py` produces an isolated vLLM 101-class mean-token-logprob cohort only after native input and 16-question score/rank checks. Existing Transformers rows are not mixed.

`postprocess_qwen3vl_v1.py` is a versioned copy of the verified independent_v5 CPU postprocessor. It preserves sample/replicate/seed/config/EOS/probability validation, the exact free matcher, frozen mean-logprob rank and three-valued question rule. Only dependency binding differs: Qwen3-VL independent production explicitly recorded `pending_separate_closed_cohort`; this postprocessor validates the now-complete new scoring cohort and writes a separate `joint_source_binding.json`. Neither source identity is rewritten or falsely presented as having a preexisting closed dependency. Full source hashes, both identities and the binding are included in the output proofs. Other models/dependency policies are rejected. A fresh output directory is required.
